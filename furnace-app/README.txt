chockchaiall-Temp – แอประบบแสดงผลการควบคุมอุณหภูมิเตาหลอมอัตโนมัติ
===============================================================

ไฟล์ในโฟลเดอร์นี้
  index.html             หน้าจอ Dashboard (เชื่อมต่อ Google Sheets ชีต furnace-log-template ไว้แล้ว)
  manifest.webmanifest   ข้อมูลแอป: ชื่อ ไอคอน สี
  sw.js                  เก็บตัวแอปไว้ในเครื่อง ให้เปิดได้แม้อินเทอร์เน็ตหลุด
  icons/                 ไอคอนแอป

ขั้นที่ 1  นำแอปขึ้นเว็บ (ต้องเป็นลิงก์ https จึงติดตั้งเป็นแอปได้)
  วิธี GitHub Pages (ฟรี)
  1. สมัคร/เข้าสู่ระบบ github.com แล้วกด New repository ตั้งชื่อ เช่น furnace-hmi เลือก Public
  2. กด "uploading an existing file" ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ icons) ลงไป แล้วกด Commit changes
  3. ไปที่ Settings > Pages > Source เลือก "Deploy from a branch", Branch: main, โฟลเดอร์ / (root) แล้วกด Save
  4. รอ 1–2 นาที จะได้ลิงก์ เช่น https://<ชื่อผู้ใช้>.github.io/furnace-hmi/

ขั้นที่ 2  ติดตั้งลงเครื่อง
  Android (Chrome)      เปิดลิงก์ > เมนู ⋮ > "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
  iPhone / iPad (Safari) เปิดลิงก์ > ปุ่มแชร์ > "เพิ่มไปยังหน้าจอโฮม"
  Windows / Mac (Chrome หรือ Edge)  เปิดลิงก์ > กดปุ่ม "ติดตั้งแอป" บนแถบหัวของ Dashboard
                         หรือไอคอนติดตั้งท้ายช่องที่อยู่เว็บ

หลังติดตั้ง แอปจะมีไอคอน "chockchaiall-Temp" เปิดเป็นหน้าต่างของตัวเอง ไม่มีแถบเบราว์เซอร์

การทำงานของแอป
  - เปิดแล้วเชื่อมต่อ Google Sheets เองทันที ดึงข้อมูลใหม่ทุก 10 วินาที
  - ถ้าเปลี่ยนลิงก์ชีตในหน้า "แหล่งข้อมูล" แอปจะจำค่าไว้ในเครื่องนั้น
  - ถ้าอินเทอร์เน็ตหลุด แอปยังเปิดได้ และแสดงข้อมูล 600 แถวล่าสุดที่เคยดึงไว้ พร้อมแถบแจ้งเตือนสีส้ม
  - เมื่ออินเทอร์เน็ตกลับมา แอปดึงข้อมูลใหม่เอง

การอัปเดตแอป
  แก้ไฟล์แล้วอัปโหลดทับใน GitHub เครื่องที่ติดตั้งไว้จะได้รุ่นใหม่เมื่อเปิดแอปครั้งถัดไปขณะมีอินเทอร์เน็ต
  (ถ้าแก้ไฟล์ใด ๆ ให้เพิ่มเลขใน CACHE ของ sw.js ด้วย ตอนนี้เป็น furnace-hmi-v4)

ข้อควรระวัง
  - ลิงก์ GitHub Pages แบบ Public ใครมีลิงก์ก็เปิดดูได้ และในไฟล์ index.html มีลิงก์ชีตอยู่
  - ชีตต้องแชร์แบบ "ทุกคนที่มีลิงก์" (ผู้มีสิทธิ์อ่าน) ตลอด แอปจึงจะดึงข้อมูลได้
